# DarkLight — Стримы и видео

> «Стримлю, прохожу, делюсь эмоциями. Залетай на стрим!»

Это личный сайт-визитка стримера **DarkLight** на GitHub Pages. Здесь собрано всё, что нужно зрителю: расписание стримов, форма для идей игр, лучшие моменты и ссылки на все соцсети.

Сайт уже доступен по адресу:  
👉 **[darklight225.github.io/DarkLightChannel/](https://darklight225.github.io/DarkLightChannel/)**

## ✨ Что есть на сайте

- **Расписание стримов** — чтобы ты точно не пропустил начало.
- **Страница лучших моментов (Highlights)** — клипы и крутые моменты с прошлых стримов.
- **Форма для идей игр** — предложи, во что сыграть в следующий раз. Твои идеи реально учитываются.
- **Страница 404** — с мини-анимациями и пасхалками (проверь, если введёшь неверный адрес).

## 🎨 Особенности и фишки

Я делал этот сайт не просто как «лендинг», а как тренировку навыков фронтенда. Вот что тут интересного с технической стороны:

- **Тёмная тема по умолчанию** + переключатель на светлую (выбор сохраняется в `localStorage`).
- **Эффект печатной машинки** на главной странице — атмосферно смотрится в тёмной теме.
- **Мини-анимации** на странице 404 и при наведении на кнопки.
- **Адаптивная вёрстка** — сайт нормально выглядит и на ПК, и на телефоне.
- **Оптимизированные изображения** — чтобы грузилось быстро даже на мобильном интернете.

## 🛠 Технологии и стек

- **HTML5** — семантическая разметка.
- **CSS3** — Flexbox, Grid, кастомные свойства (CSS Variables) для переключения тем.
- **JavaScript (Vanilla)** — логика переключения темы, эффект печатной машинки, простая валидация форм.
- **GitHub Pages** — хостинг и деплой.
